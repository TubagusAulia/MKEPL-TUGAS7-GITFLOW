# MKEPL Tugas 7 Gitflow

Git Flow

Menggunakan 2 Branch Utama:

1. Branch Utama
    Branch untuk produksi, dimana aplikasi versi stabil dan siap rilis disimpan

2. Branch Develop
    Branch untuk pengembangan, dimana aplikasi versi dalam pengembangan disimpan.


Alur Gitflow:

Peerubahan dan pengembangan aplikasi akan masuk ke branch develop, ketika tidak ada masalah, maka aplikasi akan di teruskan ke branch main
